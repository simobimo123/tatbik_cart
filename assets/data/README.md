# قاعدة كلمات الألمانية

الملف الذي تتحكم أنت في محتواه هو:

`assets/data/german_words.json`

كل عنصر يجب أن يحتوي على:

- `german`: الكلمة بالألمانية
- `translation`: ترجمة الكلمة
- `example`: جملة مثال بالألمانية
- `example_translation`: ترجمة جملة المثال

مثال:

```json
{
  "german": "gehen",
  "translation": "يذهب",
  "example": "Ich gehe heute zur Schule.",
  "example_translation": "أذهب اليوم إلى المدرسة."
}
```

يمكنك وضع مئات أو آلاف العناصر داخل مصفوفة `words`.

عند تشغيل التطبيق، تتم مزامنة الكلمات الموجودة في هذا الملف مع قاعدة البيانات المحلية.

كلمات قاعدة الاكتشاف هي الكلمات التي تأتي من هذا الملف فقط. أما الكلمات التي يضيفها المستخدم من صفحة **إضافة إلى المراجعة** فهي تدخل نظام المراجعة مباشرة ولا تدخل اكتشاف الكلمات.

إزالة كلمة من ملف القاعدة لا تحذفها تلقائيًا من قاعدة بيانات الهاتف؛ هذا مقصود حتى لا يؤدي تعديل ملف القاعدة إلى فقدان بيانات التعلم المحلية.
