# قاعدة كلمات الألمانية

الملف الذي تتحكم أنت في محتواه هو:

`assets/data/german_words.json`

كل عنصر يجب أن يحتوي على:

- `german`: الكلمة بالألمانية
- `translation`: ترجمة الكلمة
- `example`: جملة مثال بالألمانية
- `example_translation`: ترجمة جملة المثال

ويمكنك اختياريًا إضافة:

- `difficulty`: مستوى الكلمة: `easy` أو `medium` أو `hard`
- `category`: اسم مجموعة الكلمات
- `category_difficulty`: مستوى مجموعة الكلمات: `easy` أو `medium` أو `hard`

مثال:

```json
{
  "german": "gehen",
  "translation": "يذهب",
  "example": "Ich gehe heute zur Schule.",
  "example_translation": "أذهب اليوم إلى المدرسة.",
  "difficulty": "easy",
  "category": "الحياة اليومية",
  "category_difficulty": "easy"
}
```

يمكنك وضع مئات أو آلاف العناصر داخل مصفوفة `words`.

عند تشغيل التطبيق، تتم مزامنة الكلمات الموجودة في هذا الملف مع قاعدة البيانات المحلية.

كلمات قاعدة الاكتشاف هي الكلمات التي تأتي من هذا الملف فقط. أما الكلمات التي يضيفها المستخدم من صفحة **إضافة إلى المراجعة** فهي تدخل نظام المراجعة مباشرة ولا تدخل اكتشاف الكلمات.

إزالة كلمة من ملف القاعدة لا تحذفها تلقائيًا من قاعدة بيانات الهاتف؛ هذا مقصود حتى لا يؤدي تعديل ملف القاعدة إلى فقدان بيانات التعلم المحلية.

## مستوى الكلمات والمجموعات

مستوى **الكلمة** ومستوى **المجموعة** معلومتان مستقلتان:

- `difficulty` يحدد مستوى الكلمة نفسها.
- `category_difficulty` يحدد مستوى المجموعة التي تنتمي إليها الكلمة.

المقصود بالصعوبة هنا **مدى شيوع الاستعمال في الحياة اليومية**:

- `easy`: شائعة جدًا.
- `medium`: مستعملة في الواقع، لكنها أقل رواجًا.
- `hard`: مفيدة ومستعملة، لكنها أقل شيوعًا.
- `unspecified`: غير محدد.

يمكن إنشاء المجموعة من شاشة **المراجعة** واختيار مستواها، ويمكن تغيير مستواها لاحقًا. المجموعات القديمة التي كانت موجودة قبل هذا التحديث تصبح تلقائيًا **غير محددة** إلى أن يتم تعيين مستواها.

## صيغة التصدير

ملفات التصدير الحالية تستخدم الإصدار `3` وتحتوي على:

- `categories`: جميع المجموعات مع مستوى كل مجموعة.
- `words`: الكلمات، ومستوى كل كلمة في `difficulty`.
- الكلمات المرتبطة بمجموعة تحمل أيضًا `category_difficulty` حتى لا تضيع معلومة المجموعة عند نقل السجل منفردًا.

مثال مبسط:

```json
{
  "version": 3,
  "categories": [
    {
      "name": "الحياة اليومية",
      "difficulty": "easy"
    }
  ],
  "words": [
    {
      "german": "gehen",
      "translation": "يذهب",
      "example": "Ich gehe heute zur Schule.",
      "example_translation": "أذهب اليوم إلى المدرسة.",
      "difficulty": "easy",
      "category": "الحياة اليومية",
      "category_difficulty": "easy"
    }
  ]
}
```

الملفات القديمة التي لا تحتوي على `difficulty` أو `category` أو مستوى للمجموعة تبقى صالحة، وتُعامل القيم غير الموجودة تلقائيًا على أنها **غير محددة**.
